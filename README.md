# Gif-Creation-Jet-boundary-Density-and-Velocity-
This is Python code to create two gifs demonstrating the density and velocity profile of a rotating molecular jet.
I added code to define the orbit of the jet based off of the mean anomaly and eccentric anomaly of the jet.
I defined the density and velocity of the jet over time using the pulsation period and amplitude, and the radial distance of the jet, respectively.
